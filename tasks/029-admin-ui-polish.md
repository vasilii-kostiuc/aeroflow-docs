# Admin UI Polish

Status: Done  
Bounded context: Flight Operations, Announcements, Localization (presentation)  
Service: aeroflow-web, aeroflow-core (конфигурация языков)  
Change type: Frontend (UI) + конфигурация

## Goal

Закрыть мелкие визуальные несогласованности админки, найденные при ревью UI.

## Изменения

* **Статус записи справочника** — общий компонент `shared/ui/StatusBadge` на всех
  экранах админки (карточки рейсов, карточка рейса, аэропорты, дополнительные и
  экстренные объявления): один вид (`light`, зелёный/серый), подпись согласована
  с существительным («Активна» карточка, «Активен» аэропорт, «Активно»
  объявление), бейдж не обрезается узкой колонкой.
* **Маршрут в таблице карточек рейсов** — компактно «Город (CODE)»
  (`formatAirportShortLabel`), полное название аэропорта — в tooltip. Строки
  больше не раздуваются до двух линий, а колонка статуса имеет фиксированную
  ширину — исчезло обрезание «АКТИ…».
* **Шапка каталогов пресетов** — кнопка «Добавить» остаётся справа от заголовка и
  при длинном подзаголовке (раньше на экране экстренных объявлений она уезжала
  под текст).
* **Название языка** — `ro-MD` в конфигурации core записано с диакритикой:
  «Română» вместо «Romana».

## Out of Scope

* пагинация и счётчик «Всего» в справочнике аэропортов;
* мобильная вёрстка таблиц админки;
* группировка навигации («Справочники» / «Работа»).
